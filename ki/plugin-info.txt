Das Plugin soll einen sinnvollen Offset eines auszuwählenden Imagery-Layers automatisch einstellen.

Das Plugin öffnet einen Dialog (AdjustOffsetDialog.java). Darin kann man in einer ComboBox einen Data Layer und über eine andere Combobox einen Imagery-Layer auswählen. Außerdem ist ein JSON-Schnipsel mit Konfigurationsparametern enthalten.

Nach dem Starten der Offset-Berechnung per "OK" Knopf wird aus einem Ausschnitt des Imagery Bildes per Canny Funktion eine Kanten-Extraktion durchgeführt. Die Kanten werden dann gegen die Gebäude-Objekte im Data Layer verglichen und daraus wird ein Minimum der Kantendifferenzen ermittelt.

In einem temporären Folder d:\temp werden zur Analsysezwecken das Imagery-Bild (offset-imagery.png), das aus dem Data Layer ermittelte Biold (offset-geometry.png) und das Canny-Bild (offset-canny.png) ermittelt. Alle Bilder haben die gleiche Auflösung. Einige Statistik-Infos werden auf die Console geschrieben.

Aktuell funktioniert das Plugin und die Generierung der Bilder nach d:\temp bereits. 
Im Dialog (AdjustOffsetDialog.java) befindet sich ein Textfeld "Debug Configuration",  das einen JSON-Schnipsel mit Eigenschaften anzeigt. Eine dieser Eigenschaften ist boolean und heißt "SelectedBuildingsOnly". Ich möchte diese Eigenschaft aus dem JSON entfernen und stattdessen im Dialog eine Checkbox anzeigen.
